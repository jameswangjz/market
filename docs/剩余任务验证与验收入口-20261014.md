# 剩余任务验证与验收入口

## 最新规则

- 不新增独立模型API产品类型：模型服务属于API应用；模型产品固定为文件下载。
- 业务审核仅允许数据产品经理（`product_manager`）和平台管理员；独立业务审核角色及`ywsh`固定账号初始化取消，历史账号安全停用，历史审计保留。角色移除的部署验证单独记录，不以旧审核证据代替。
- 企业与API产品共享调用凭据；同版本续费延长期限，不叠加当前周期配额。API按订阅月、每日限额按北京时间自然日重置，升降级保留用量。
- 四级审核后API/SaaS进入待接入验证，健康验证成功才发布；连续三次健康异常不暂停新购。
- 线上交付必须验证文件授权、网关授权或SaaS租户/管理员/入口，不以生成字符串视为完成。自动失败三次、间隔10秒后转人工。
- 提供方接入凭据与购买方调用凭据分离；文件和API凭据仅买方企业超级管理员、管理员可取得。
- 开发与验证通过记为待验收，用户前端确认后才记为已完成。已完成状态不被脚本回退。
