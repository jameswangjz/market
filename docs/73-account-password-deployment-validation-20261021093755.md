## 人工验收入口与限制

1. 登录 /console，左侧底部“修改密码”；侧栏收起时显示钥匙图标。填写原密码和两次新密码，成功后重新登录。
2. 退出登录，在登录页点击“忘记密码”。已绑定且验证邮箱的账号可以申请随机六位邮箱验证码，10分钟有效、错误最多5次。
3. 邮件使用现有SMTP配置。自动化测试模拟SMTP；尚未执行真实邮箱收件验收，须用本人控制的邮箱验证送达。
4. 仅绑定手机且没有已验证邮箱的账号暂不支持自助找回，不使用固定短信开发验证码绕过密码验证。
5. 本轮未运行真实浏览器视觉端到端测试；已完成组件编译、交互逻辑测试、构建及部署后HTTP链路验证。
