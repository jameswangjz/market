# 业务审核角色收敛

## 最新需求

业务审核由平台数据产品经理（`product_manager`，固定账号`sjcp`）或平台管理员（`super_admin`）执行。数据产品经理不是产品所有者，产品归属仍依据登记人、所属企业和企业权限确定。

取消独立业务审核人员角色（`business_reviewer`）及`ywsh`固定账号初始化。流程继续为业务审核、质量审核、安全审核、运营审核；其余审核角色和权限不变。

## 实现

- 从平台角色目录、固定账号配置、前端权限及角色显示中移除独立业务审核角色。
- 旧角色账号和`ywsh`账号停用，不能使用密码或已有登录令牌继续访问；不自动提升为数据产品经理。
- 启动迁移保留账号身份、密码摘要及历史关联，不删除历史订单或审计。首次停用记录系统操作的变更前后值；重复启动不重复生成迁移审计。
- 提交产品审核时仅通知数据产品经理及平台管理员；不通知已退役账号。
- 历史审计中允许保留旧角色标识，不能据此恢复当前权限。
