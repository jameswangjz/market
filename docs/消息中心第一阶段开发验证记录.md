## 开发任务导入

通过 scripts/import_message_tasks.py 将详细任务清单中的28项任务导入开发进度控制台。脚本按任务ID去重，不覆盖已有任务进度。

本阶段结束时：已完成1项（需求与架构设计），进行中7项，待开发20项。

## 本阶段实现

1. 持久化消息与用户收件记录、历史站内通知幂等迁移。
2. 服务端分页、标题及正文检索、未读统计。
3. 阅读、归档、用户维度软删除、恢复及批量操作。
4. 紧急消息显式确认；阅读不自动确认，未确认时禁止归档和删除。
5. 顶部消息入口、未读数量、紧急提醒和消息中心页面。
6. 产品审核通知接入新消息存储，保持发送方事务边界。

## 验证结果

backend/tests/test_message_center.py 的6项自动化测试通过：

- 超过100条未读消息的完整计数与分页。
- 收件人权限隔离与软删除隔离。
- 紧急消息阅读、确认和删除限制。
- 批量操作遇到越权目标时整体回滚。
- 消息幂等及事务回滚。
- 历史迁移幂等，未知历史回执时间不伪造。

前端生产构建通过。开发环境API登录正常，消息汇总与列表返回正常；管理员历史通知迁移后返回4条未读通知。API及Web部署滚动更新成功。

本阶段未进行浏览器端完整端到端回归，不将其计为通过。
