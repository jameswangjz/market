## 2. 配置方法

1. 在平台上，由产品提供方企业超级管理员或管理员下载该 SaaS 产品的统一接入配置 JSON。
2. 打开上述管理地址，使用本机私密文件中的管理密钥登录。
3. 点击“新建客户端”，按下表填写并保存。

| 页面字段 | 统一接入配置 JSON 字段 |
| --- | --- |
| 客户端 ID | `oidc_sso.client_id` |
| 客户端密钥 | `oidc_sso.client_secret` |
| 产品 ID | `product.id` |
| 产品名称 | `product.name` |
| 签发方 issuer | 自动使用模拟服务配置，当前为 `http://192.168.10.10:30080`，不可编辑 |
| 回调地址 | 自动使用 `http://192.168.10.10:30083/sso/callback`，不可编辑 |

平台产品登记的 `oidc_sso.redirect_uris` 必须包含上述回调地址。若不同，应先修正平台登记，不能在模拟服务侧随意替换回调地址。

`oauth2_api` 是机器接口调用凭据，不能填入上述 OIDC 表单。模拟 SaaS 的机器接口沿用现有平台 Token 内省验证；这次没有新增一套机器凭据配置机制。

编辑时客户端 ID、产品 ID 不可更改；密钥留空保留原值，填入新密钥则更新。密钥改变会清除该客户端的旧登录流程、会话和 OIDC 映射，不删除其租户、用户或部门。

## 3. 验证及订单恢复

“检查连接”通过固定可信后台地址查询平台 OIDC Discovery，核对公开 issuer 与端点，避免任意 URL 抓取。检查成功只代表连通性及发现配置正确，不能证明密钥有效或完整 SSO 成功。

完整业务链路为：配置客户端 → 平台完成 SaaS 开通及状态核验 → 交付成功 → 有权限的购买方从订单／我的应用启动 → 平台登录及授权 → OIDC 授权码和 PKCE 回调 → SaaS 建立用户会话。

## 4. 安全边界

- 管理页面仅在 `MOCK_SAAS_ENABLE_TEST_ADMIN=true` 时启用；默认关闭。
- 配置列表、保存结果、校验错误均不回显客户端密钥。
- 管理密钥仅在页面内存中保留，不写浏览器 localStorage／sessionStorage；退出或离开页面清理。
- 页面及接口禁止缓存，并设置 CSP、禁止被 iframe 嵌入及 no-referrer。
- 配置写入现有私有 SQLite/PVC，重建容器后保留。
- 当前 HTTP 地址仅用于受控开发网络，不能作为生产环境凭据传输方案；生产部署应使用 HTTPS 和更严格的访问控制。
