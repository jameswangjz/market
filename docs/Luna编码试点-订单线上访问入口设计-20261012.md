# Luna 编码试点：订单线上访问入口

## 分工与范围

主 Agent 使用当前模型完成需求、契约、设计、代码审查、测试与部署验证。前后端编码 Agent 明确使用 `gpt-6-luna`、`medium`。本轮推进 TRD-FE-006 及 TRD-BE-012 的安全访问入口部分，不将 API/SaaS 自动履约工作进程、升降级 Saga 或全部四种交付的真实验收标为完成。

不操作已保留订单 ORD-261012005144E1B3 及其临时产品、依赖和接入配置。测试新增独立且不公开上架的夹具，避免再次产生真实用户购买测试产品的情况。

## 访问契约

扩展现有 `GET /api/orders/{order_id}/delivery-access`，保留文件响应与下载限制逻辑。所有响应禁止缓存；读取不产生凭据、不刷新网关、不改变订单交付状态。

统一字段：`order_id`、`method`、`ready`、`reason`、`files`。只允许已实名、有效购买企业的超级管理员或管理员读取；平台角色、普通成员、提供方和跨企业账号均不可读取买方入口。

- 文件：既有冻结文件、扫描状态、购买方授权与订单下载次数校验不变。
- API/模型 API：新版订单须全额支付、未退款、履约完成；产品未安全下架，当前企业+产品订阅权益有效，选择当前权益版本的有效路由。返回相对网关路径、当前版本、期限、当前权益限额与凭据管理接口路径；不返回 Secret、Key 明文、哈希、上游地址、成本或提供方接入信息。没有可用共享凭据时明确说明需配置，仍提供配置入口。
- SaaS：严格核对订单、订阅、企业和产品归属，使用既有应用访问与 OIDC eligibility 规则。只返回订阅标识、期限及同源启动接口，不直接信任产品地址。
- 新增 `POST /api/orders/{order_id}/delivery-launch`，重新校验购买方、订单和 SaaS 权益，委托既有应用启动逻辑返回已验证的应用地址；启动保留审计，失败拒绝且不改变状态。
- 历史无完整快照订单及线下订单明确标识不可用，不推测其交付信息，也不迁移其记录。

网关完整地址使用部署配置 `API_GATEWAY_PUBLIC_URL` 的 HTTP/HTTPS 公共 origin 加相对路由路径，返回 `api.gateway_url`。地址不能含用户信息、查询、片段、反斜线或控制字符，不使用请求 Host 推断。开发为 `http://192.168.10.10:30082`，与平台前端 30080 分离；生产需配置网关 HTTPS origin。未配置或配置不合法时 `ready=false`，但符合权限的凭据管理入口仍可用。前端仅展示地址，不自动发起网关调用。

## 前端

订单第二列和详情使用同一权限判断；文件为“下载文件”、API/模型为“查看接入信息”、SaaS 为“访问应用”。API 弹框展示当前版本、调用路径、期限和额度，提供进入既有凭据管理区域的操作，Secret 不进入列表或 URL。SaaS 通过同源 POST 启动，返回地址结构化校验后跳转。

保留文件下载状态机。所有异步请求绑定用户、登录 Token、企业、订单及请求序号；切换上下文、退出登录或关闭弹框后，迟到响应不得显示旧企业信息或触发导航。错误给出可重试状态，不静默失败。弹框沿用现有风格，桌面和移动无横向溢出。

## 验收与质量记录

正常文件/API/模型/SaaS、没有凭据、停用凭据、未支付、未交付、退款、到期、安全下架、跨企业、普通成员、平台角色、订阅归属错配均验证。读取端点不能触发 APISIX 更新、创建凭据或修改状态；当前版本不能误取已过期或未来版本。SaaS 启动复用已有 URL 安全检查及审计。

主 Agent 独立运行后端、前端回归和构建，审查权限、信息泄露、迟到响应与路由安全；部署标签遵循 YYYYMMDDHHMMSS-GitSha。只有执行过的测试写通过，部分完成任务保留进行中。

记录每个编码 Agent 的精确模型/档位、任务边界、耗时、首轮审查问题、返工次数和最终测试结果。Token 仅采用工具或平台实际提供的计量；未提供时记“不可获取”，不以代码行数或运行时间推算。该试点不构成与上一模型的同输入随机对照，不能单凭一个批次宣称质量或成本提升。
