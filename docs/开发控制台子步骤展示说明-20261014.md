# 开发控制台子步骤展示

## 范围

将新版商城、售后、退款及 SLA 的32项任务、124个子步骤显示在开发进度控制台。子步骤以已确认的任务定义为来源，保持原顺序，提供稳定编号。历史任务没有子步骤定义时不生成虚假步骤。

## 展示与权限

- 控制台显示子步骤总数，每项任务可展开查看完整子步骤。
- 支持批量展开和收起，便于检查执行清单。
- 任务原有状态和进度保持不变。
- 子步骤暂未建立独立执行记录，展示“未单独标记”，不根据父任务进度自动推断已完成。
- 仅平台系统管理员可访问开发进度页面及其接口。

## 数据与验证

子步骤定义随应用版本发布，接口按实际返回任务汇总数量；不变更数据库结构，不修改业务数据、父任务状态或进度。验证定义数量、稳定编号、历史兼容、权限和展开交互。
