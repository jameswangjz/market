# 控制台体验与SLA矩阵管理需求

编号：30；生成时间：2026-10-16 15:50:59（北京时间）。本文件覆盖本轮与旧界面、旧规则编辑方式冲突的要求；不改变既有交易、退款、审核权限。

## 1. 范围与权限

交付与售后、审计日志、用户与企业沿用数据与服务的检索、分页视觉规范。所有列表先应用身份及企业可见范围，再筛选、计数、分页；不得通过总数或候选选项泄露其他企业信息。原未分页接口消费者保持兼容。

交付与售后三个Tab独立保留筛选和分页，页大小、当前页/总页数、跳页控件不得错行或溢出。筛选重置回第一页。审计检索在常规桌面两行展示，窄屏允许换行；动作以中文展示，原动作代码保留在详情，不改历史存储。

用户、企业两个Tab各支持检索和分页；支持已邀请、待激活成员，权限范围不因分页改变。空结果、删除后空页及切换条件需正确回退。

## 2. SLA四个工作区

1. SLA保障总览：当前统计、立即考核、周期结果及异常定位；历史考核保留原口径标识。
2. 服务级别与支持权益：标准级、企业级、战略级依次展示，自定义级别置后。完整展示已确认CSV矩阵，仅平台系统管理员、平台运营人员可修改目标值与预警阈值。支持天数、小时、日历、单位、责任方、计时/暂停口径、统计周期及样本规则只读。
3. 企业服务级别绑定：展示各企业当前有效级别，未绑定默认为标准；按企业名称、级别、到期时间和操作人检索及分页；修改必须填写原因并审计，历史记录可查。
4. 冻结承诺与指标证据：展示既有订单/工单冻结承诺及原始指标证据，保留既有授权隔离。

## 3. 矩阵及生效规则

以《SLA级别指标配置矩阵-提前预警修正版-20261014.csv》及已确认代码值为迁移基线；战略级紧急首次响应为360分钟，不恢复15分钟。时限类指标使用分钟，支持日/小时保留原单位。

下限型指标（可用率、交付及时率）预警值不低于目标，上限型指标（耗时、错误率）预警值不高于目标；百分比0～100，时限及延迟为正有限数。拒绝未知字段及修改只读元数据。

每次保存生成新矩阵版本，保存修改前后、操作者、时间；仅后续新冻结承诺生效。已有订单、工单、评估、日历快照不追溯修改。新建自定义级别必须从标准/企业/战略之一复制完整矩阵和固定日历，不能仅创建名称。

移除旧“规则配置”编辑入口，旧配置历史只读；旧写接口不能继续旁路修改新承诺。考核使用冻结指标，不能仅更新界面而继续使用硬编码阈值。

## 4. 绑定有效期

不设置到期时间即长期有效；设置到期时间必须晚于生效时间。到期后新冻结承诺自动回到标准级，不回落到更早绑定，也不改变历史承诺。到期恢复记录幂等审计，读取接口不得随意产生重复业务变更。绑定和到期并发须有确定顺序。

## 5. 验收

验证矩阵权限、范围与方向、完整复制、冻结前后差异和旧快照不变；验证到期边界、长期绑定和到期审计不重复；验证用户企业跨租户隔离及筛选计数；浏览器集中验证四Tab、桌面/窄屏布局、分页和审计中文。真实银行、交易重建和业务测试数据删除不在本轮范围。
