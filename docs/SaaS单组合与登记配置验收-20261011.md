# SaaS单组合与登记配置验收

## 开发范围

### TRD-FE-004 登记配置

- 每版本新增 `compatibility_mode`（compatible/breaking）、`compatibility_notes`；新版和历史字段默认值兼容，已售字段继续冻结。
- SaaS租户交付新增 `oidc_redirect_uris` 字符串数组，前端多行编辑，后端JSON持久化。
- 严格完整HTTPS回调地址，不允许通配符、用户信息、片段、反斜杠、空白或无效端口。HTTP仅允许准确的localhost、127.0.0.1、market-mock-saas开发主机。
- 非SaaS租户产品不可配置回调；已售产品的回调不可覆盖。这只是登记白名单，不代表OIDC协议或SSO已经实现。
- 修复迁移字典的重复键覆盖，保留版本成本和额度字段，并新增兼容性字段；旧库补字段与重复执行已测试。

### TRD-BE-013 唯一租户组合

- 新增 `saas_combination_bindings`，企业+产品唯一，subscription_id唯一；不对历史saas_subscriptions加企业+产品唯一约束，不删除历史多租户。
- 新版购买在同一事务内预留未开通租户并关联订单；不付款、不调用第三方、不启动计时。重复购买关联同一租户；有效期仍由实际成功交付后的订阅期限模块管理。
- 历史单租户自动复用；历史多个租户必须通过 `saas_subscription_id` 明确选择。首次绑定后禁止切换到另一个独立租户。
- 不同版本要求进入版本变更流程；关闭租户不得替换为新租户，须先恢复。旧新增独立租户接口同样受限制。
- `GET /api/products/{product_id}/saas-subscription-targets?enterprise_id=...` 返回当前企业候选租户和绑定状态，仅有资格的企业管理员可访问。
- 锁顺序为产品、企业、组合绑定、租户；创建、审计、订单在调用方事务内提交，失败完整回滚。

### TRD-BE-011 配额迁移保护

- 迁移预览/执行增加拓扑、数据库键数量、来源数量、计划/键字节数、扫描页数和时间预算保护；Python预检与Lua原子脚本内再次检查。
- 仅支持单机主节点；Redis Cluster、未知拓扑、副本、大库明确拒绝，不进行不完整SCAN迁移。
- 增加只读预检入口，修复接近Lua安全整数上限的JSON计数精度；保守迁移和重复执行不放大授权。
- 扫描100ms是检查式预算，不是硬实时停顿保证。历史日/月计数不能精确恢复订阅周期，保守累计水位可能提前耗尽额度；真实历史迁移尚未验收。
