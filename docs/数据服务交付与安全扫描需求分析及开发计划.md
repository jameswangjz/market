# 数据服务交付与安全扫描需求分析及开发计划

## 1. 已确认业务规则

### 1.1 产品审核与撤回

- 企业超级管理员、企业管理员仅可撤回本企业处于“待审核”的产品。
- 撤回后产品状态变为“草稿”。
- 撤回必须填写原因，并保留原审核记录、撤回人、撤回时间和撤回原因。
- 平台管理员、平台运营人员可以执行平台退回、下架和安全策略自动下架。

### 1.2 文件下载交付

- 文件绑定到具体产品版本，版本发布后文件不可被覆盖。
- 支持 zip、tar、tar.gz 等压缩格式，单文件小于10GB。
- 下载次数按订单独立计算；0表示不限制。
- 达到下载次数后，该订单的下载链接失效，不影响其他订单。
- 每次下载记录订单、用户、文件、时间、结果、失败原因和客户端请求标识。
- 上传时执行扩展名/MIME检查、压缩包安全检查、ClamAV病毒扫描和Presidio敏感信息扫描。
- 自动扫描结果形成报告，由安全审核人员查看并确认。

### 1.3 API服务与模型API

- 登记时填写提供方后端地址，审核通过后建立网关路由。
- 订单支付后，为订单生成独立网关访问地址、访问凭据、额度和限流策略。
- 千次、万次等计费单位统一换算为整数额度，如10000、100000。
- 额度、分钟限流、日配额、月配额按订单独立保存和统计。
- 订单取消后额度归零；退款后额度归零，并按照已使用额度计算退款扣减；额度耗尽后网关访问失效。

### 1.4 SaaS租户/权限开通

- 保存SaaS应用访问地址和租户/权限开通接口地址。
- 平台审核通过后自动生成OAuth2接入配置。
- 一个企业可以购买同一产品的多个版本和多个独立租户，订单保存独立租户标识。
- 月付采用购买日对应日期顺延：目标月份没有对应日期时取该月最后一天。例如1月31日购买一个月，2月到期日为2月28日或29日。
- 提前续费从当前到期时间继续顺延，不按自然月重置。

### 1.5 线下交付

支付后自动进入“履约中”；服务方提交履约完成后进入“履约完成待审核”；购买方审核通过后进入“履约完成”。拒绝必须填写原因并回到履约中，所有状态变化写入审计日志。

### 1.6 产品Logo

- 产品必须支持Logo上传，尺寸精确为380×280。
- 支持SVG和常见图片格式。
- SVG清除脚本、外部资源和事件属性，保存原图并生成展示缩略图。
- Logo绑定产品，不绑定版本。

## 2. 安全扫描架构

文件安全检查采用“平台策略引擎 + Presidio + ClamAV”组合：

1. 平台检查扩展名、MIME、大小、压缩包目录、路径穿越和压缩炸弹风险。
2. ClamAV在`market`命名空间本地部署，病毒库使用持久化卷，并由定时任务周期更新。
3. Presidio扫描解压后的文本、CSV、JSON等可解析内容，识别身份证号、手机号、邮箱等敏感信息。
4. 扫描报告记录引擎版本、病毒库版本、扫描时间、文件摘要、发现项和处置建议。
5. 扫描失败、病毒命中或高风险发现不得自动通过安全审核。

ClamAV负责恶意代码检测，Presidio负责敏感信息识别，两者不能互相替代。

## 4. 分阶段计划

1. **阶段一：安全基础**：SEC-001至SEC-005、OPS-001。
2. **阶段二：产品登记和审核**：PROD-001至PROD-003、FE-001。
3. **阶段三：API及模型额度**：API-001、API-002、FE-002。
4. **阶段四：SaaS订阅和线下履约**：SAAS-001、SAAS-002、DELIVERY-001。
5. **阶段五：集成验证**：QA-001，完成控制台任务状态、部署记录和验收报告归档。

## 5. 实时监控口径

开发控制台按任务的`todo`、`in_progress`、`review`、`blocked`、`done`统计数量；每项任务必须同步进度、依赖、验收标准、操作记录和最后更新时间。部署标签使用`YYYYMMDDHHMMSS-GitSha`格式。
