## 2. 功能实现

新冻结的SaaS OPEN、激活/续费RENEW、CHANGE、退款缩期、STATUS及用户/部门操作包含 `reconciliation_context`。包括产品、企业、订阅、租户、订单ID/订单号、订单时段及订阅截止时间；没有单一订单的租户操作允许订单为空。

OPEN尚未交付时不编造起止时间，采用 provisional。实际激活后使用冻结时段；升降级提供受影响订单时段列表，保留原有第三方真实切换回执；退款缩期携带原截止、新截止及退款ID。模拟SaaS持久化关联上下文、首次受理时间和实际截止；STATUS只读返回最近保存的上下文，旧请求重放不回退当前状态。

旧操作请求及历史资源计划不补写新字段，继续按原内容重试。旧接口中没有真实订单关联的操作不会伪装成已具备订单号；后续对账查询可读取已有实际关联。

新增只读接口：

```http
GET /api/provider/products/{product_id}/entitlements?page=1&page_size=50
Authorization: Bearer <产品提供企业超级管理员或管理员的平台登录令牌>
```

支持订单ID、订单号、购买企业和时段筛选；返回原始订单版本、登记时段、实际权益、订阅/租户标识及退款/版本变更关联。原始日历期限与退款后的实际期限分别展示。查询支持历史下架及到期记录，但不会恢复其权益；证据异常不回退到原始未退款权益。

API服务不新增提供方OPEN/RENEW接口，仍由网关控制期限/额度。本次提供主动只读查询，不提供权益Webhook或新的机器对账客户端，不允许买方API Key、平台内部资源Token读取提供方对账数据。
