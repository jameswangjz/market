## 统计边界与后续衡量

原仓库agent-cost.py与test-turns.py读取Claude专用message.usage和Bash工具结构，不可直接据此声称当前Codex成本下降；后者默认正则还漏掉本项目常用unittest及node --test。仓库自述7任务收益不是本项目收益，不能直接外推。

先在后续约6个有界任务中记录模型、测试次数、工具输出量、耗时、重试及晚发现缺陷；只有取得可比的实际用量记录，才能报告Token成本变化。不能用字符数换算精确Token，也不能把累计用量重复相加或把缓存命中量当成实际费用。必须同时检查质量门禁和返工是否恶化。

本次验证只证明日志摘要方案可用且能正确保留失败，不证明长期多代理方案已经节省实际账单。
