# 已补差订阅升降级的资金归属与增量设计

## 已确认规则

用户确认：已有外部补款的订阅发生升降级时，原版本未使用补款随原版本冲回，形成原补款方返还权益，不自动转入新版本。买方只支付或退还既有差价算法确定的金额。返还权益不等于已付款。

## 资金示例与守恒

原买方实付150元、外部补款10元、最终清算收入160元、提供方成本100元。切换时原版本剩余50%，新版本剩余价格150元：

- 原版本财务收入冲回80元、成本冲回50元；均按最终确认基线的50%计算。
- 目标版本重新计入150元，成本及规则使用目标版本冻结快照。
- 买方升级补款75元，即150减原买方剩余金额75，不因外部补差改变买方实付。
- 原补款方形成5元返还应付，不转入目标版本，不自动付款。
- 财务收入净增70元，加原补款方返还义务5元，与买方补款75元对应。

本例不将新旧版本收入差70元冒充实际支付75元，不改写已完成的资源切换、支付和经济回执。

## 增量接线边界

1. 原始交易经济段与最终清算基线分别保留。基线收入不同于原经济段收入时，必须验证独立补差凭证，生成显式资金投影，不简单取消现有拦截。
2. 旧版本收入、成本和收益冲回均以最终基线按原经济段未使用比例投影。跨多段按各段分别计算，累计分币不得重复占用原资金和收益。
3. 版本变更没有对应买方普通退款时，不伪造退款记录或使用要求真实退款外键的证据表。版本变更返还权益需独立关联变更、经济段、旧清算单和原补款凭证。
4. 在清算资金台账中独立记录原补款方返还应付，不计为第六类利润。仅同主体、同币种、准确来源允许抵扣；付款登记须独立复核。
5. 新版本不继承未使用补款。祖先基线存在补款凭证仅用于追溯，不应自动将新版本普通退款认作继续使用旧补款。
6. 同版本续费的未来经济段逐段处理，不增加或重置当前配额；仍保留原有资金和资源切换失败的补偿约束。
