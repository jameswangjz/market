# SaaS统一接入配置下载

## 需求与权限

提供方完成 SaaS 产品四阶段审核后，由平台自动生成独立的 OAuth2 接口客户端和 OIDC 登录客户端。前端不再分别下载两个文件，统一为“下载接入配置”，得到产品级 JSON 配置文件。

提供方企业的已实名、已激活超级管理员和管理员均可下载，成员关系须为有效状态。多企业用户按产品所属企业校验，不依赖当前选中的企业。购买方、企业普通成员、平台内部角色均不能下载该提供方配置。

## 功能设计

- 路由：`GET /api/products/{product_id}/saas-integration-credentials-download`，使用平台登录 Bearer Token。
- 产品状态：仅 SaaS、租户/权限开通、待接入验证或已发布。
- 文件结构：`schema_version`、`product`、`oauth2_api`、`oidc_sso`、`instructions`。
- OAuth2 分区用于平台获取机器令牌及 SaaS 资源服务验证管理接口请求；OIDC 分区用于 SaaS 服务端用户授权码登录，采用 PKCE S256。
- 两套客户端和密钥保持独立。文件合并不轮换密钥、不重建客户端、不影响既有订单和 SaaS 会话。
- 登录客户端为产品级配置，与具体购买方无关；用户令牌、企业身份与租户权限独立验证。
- 任一客户端缺失、停用或 OIDC 密钥不可恢复时返回 409，不下载部分配置。旧单独下载接口保留兼容。
- 响应 `Cache-Control: no-store`，安全附件文件名；审计记录操作人与产品，不记录原始密钥。
