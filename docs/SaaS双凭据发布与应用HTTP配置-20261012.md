# SaaS双凭据发布与应用HTTP配置

## 发布与凭据

SaaS租户/权限开通产品完成业务、质量、安全、运营审核后，在同一事务内创建两套独立客户端。产品进入待接入验证，不能仅凭生成凭据认定交付成功。

|用途|授权方式|使用方|授权范围|
|---|---|---|---|
|平台调用SaaS租户、用户、部门管理接口|OAuth2 client_credentials|平台是调用方，SaaS是资源服务|saas.tenant saas.user saas.department|
|企业用户单点登录SaaS|OIDC授权码+PKCE S256|SaaS是登录客户端，平台是身份提供方|openid profile email|

产品提供企业的已实名超级管理员、管理员可下载一份SaaS应用接入配置JSON文件，文件内分别包含OAuth2接口凭据和OIDC登录凭据。入口统一为“下载接入配置”；原单独下载接口仅保留兼容。购买方、普通企业成员、平台角色账号不得下载提供方密钥。公开商城、审核日志和普通产品接口不得输出密钥。下载操作记录审计，响应禁止缓存。统一下载的设计及验证见《SaaS统一接入配置下载-20261012.md》；下文历史双下载证明记录保留。

重复发布沿用既有客户端，不自动轮换密钥或重新启用已停用客户端。OIDC密钥使用独立持久化加密密钥加密保存，同时保存校验摘要。历史仅保存摘要的客户端不能恢复原密钥，须走受控轮换流程，禁止悄悄生成替代密钥。

## 应用地址策略

系统配置提供应用接入地址允许HTTP开关，默认关闭。配置持久化在PostgreSQL，多副本及交付Worker共用同一配置，不依赖重新构建前端。

适用于API/模型API上游地址、SaaS应用访问地址、SaaS管理接口地址以及产品OIDC回调地址。开关仅决定是否接受HTTP协议，不取消地址格式、回调精确匹配及上游SSRF校验。平台自身OIDC发行者地址仍由部署配置管理。

关闭后，新登记、修改及接入验证应遵守HTTPS要求；不自动删除订单、切换上游地址或轮换凭据。依赖HTTP的应用应先迁移HTTPS再关闭，避免交付和登录失败。

## 模拟应用与验证

开发环境模拟SaaS浏览器地址为http://192.168.10.10:30083，内部管理接口为http://market-mock-saas:8200/isv.php，回调为http://192.168.10.10:30083/sso/callback。仅开发环境明确启用HTTP。

自动交付依次持久化开通操作、同步企业超级管理员、检查租户和应用状态、激活订阅期限并再次核验结果。失败按照10秒间隔最多三次尝试，进入异常后转人工处理，不强制标记成功。操作具备稳定幂等键，不生成额外支付订单。

验证范围包括发布事务回滚、重复发布凭据稳定、下载权限、密钥脱敏、HTTP开关即时生效、自动开通及续费、失败重试、真实模拟服务Token校验和浏览器SSO。最终运行验证结果另行记录，不把本地测试等同于开发环境验收。
