## 1. 验收原则

入口：公开商城 `http://192.168.10.10:30080/`；后台 `http://192.168.10.10:30080/console`。

逐组验收，不要求每一个小改动都重复完整交易。每条结果记录：任务编号、测试企业/角色、对象业务编号、操作时间、实际结果、截图或审计编号。通过后由用户确认任务从 review（待验收）转 done；开发代理不能代替用户确认。

企业角色以当前选中的企业为准，多企业用户先选择正确企业和提供方/消费方身份。平台账号不属于企业，不借用其身份模拟企业购买。仅平台系统管理员可查看开发进度；平台运营、产品经理、质量、安全、交付监控、财务及企业账号均不应看到。

请新建自有测试产品、订单和用户，不删除或变更受保护订单 `ORD-261012005144E1B3` 及依赖产品。不要向公开截图或文档复制密码、OAuth Secret、API Key 或完整个人实名信息。

## 2. 当前环境限制

本次部署复核发现 Redis 重启，旧计费游标保留但 Redis 计费流和来源标记缺失，API 计费采集 worker 安全拦截。其他部署及健康入口可用，业务源码匹配 `5706151`。本清单不是“全部部署健康”的证明。

在明确恢复方案之前，可以验证商城、权限、登记、售后、SaaS、文件及展示；不得将 API 缺失用量作为零用量退款，不承诺当前环境完整 API 自动退款链路通过。真实银行支付/退款未接入；当前资金执行为模拟流程。
