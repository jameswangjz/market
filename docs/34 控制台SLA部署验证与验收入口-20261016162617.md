## 4. 建议验收顺序

1. 交付与售后：逐个Tab查看检索、分页，改变每页数量并跳页；退款控件应与另外两个Tab一致。
2. 审计：检查桌面八项条件为两行，查看动作中文，点击事件可看原始代码。
3. SLA总览：查看统计、周期结果及异常证据入口；历史规则只能查看。
4. 服务级别：核对战略级紧急首次响应360分钟；展开只读参数；修改目标/预警并保存，验证错误方向被拒绝。建议使用新复制的自定义级别，避免影响后续真实新承诺。
5. 企业绑定：按名称、级别、操作人及到期范围检索；选择测试企业填写原因调整。确认无到期为长期、到期恢复标准，旧订单和工单的冻结内容不变。
6. 用户与企业：两个Tab测试名称等条件、零结果、页大小及跳页；用企业账号确认只看授权范围，待激活成员仍可见。
7. 开发进度：检索`SLC-`，核对11项待验收；通过后再确认已完成。
