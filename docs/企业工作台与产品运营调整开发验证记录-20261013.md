## 4. 验收入口

平台管理员/运营人员在“系统设置 → 产品目录”维护两级目录。企业管理员在后台右上角选择当前企业及提供方/购买方视角；提供方“数据与服务”仅显示当前企业产品。企业超级管理员可查看本企业提供方运营总览。

买方管理员在已交付 SaaS 订单详情下部进入“用户管理”“部门管理”；检查左右树、所选/全部箭头及移除确认。当前浏览器验证为只读展示，真实同步测试使用隔离测试企业通过后端操作，因此浏览器大批量操作仍属于后续回归。
