# 订阅配额迁移与续费界面验收

## 本批范围

继续 TRD-BE-011 的历史计数切换保护、TRD-FE-009 的真实续费界面验收，并核对 TRD-QA-002 的期限与配额验收证据。升降级、SaaS 首购/SSO 和财务补偿不在本批完成范围。

## 原子切换

旧网关请求在读取凭据元数据后，可能恰好遇到切换。旧 Lua 计数脚本现在在 Redis EVAL 内重新检查 `mode`，发现新订阅模式后不再增加旧计数，重新读取新策略并按稳定组合键计数。

无历史用量的首次同步也使用 EVAL 完成“确认旧计数为零＋写新元数据”，而不是先扫描、后写入的非原子步骤。迁移前后以及凭据轮换均不删除旧计数、不重置新日/月用量。

## 显式迁移工具

脚本：`scripts/subscription_quota_migrate.py`。仅允许已实名、启用的平台管理员在后端运行环境执行。先预览，再确认执行；预览文件不含 API Key、OAuth Secret 等密钥。

```bash
PYTHONPATH=/app python /tmp/subscription_quota_migrate.py \
  --combination-id <订阅组合ID> --actor admin@market.local \
  --request-id <唯一操作编号> --plan-file /tmp/quota-plan.json

PYTHONPATH=/app python /tmp/subscription_quota_migrate.py \
  --combination-id <订阅组合ID> --actor admin@market.local \
  --request-id <相同操作编号> --plan-file /tmp/quota-plan.json \
  --execute --acknowledge-conservative-usage --cutover-guard-verified
```

执行前必须确认所有 APISIX 副本已经滚动更新到带原子切换保护的版本，不能在新旧 Lua 插件混跑时执行。预览最多有效 30 秒，同时不得跨越分钟、北京时间日界或订阅月界；到期须重新预览。执行时再次核对数据库中的凭据集合、冻结策略及键集合。

Redis 在同一个 EVAL 中校验所有来源、目标、元数据类型和计数，检查成功后才写入目标计数和凭据策略。已有新用量加上旧用量水位，不能取较小值；重复操作使用持久化回执，不重复增加用量。数据库审计记录操作人、组合、请求号、前后计数；Redis 回执保留用于执行成功但数据库审计失败后的恢复。

## 保守口径及尚未完成项

旧网关按 UTC 自然月/日计数，无法据此精确还原任意订阅日对应的月用量。因此工具仅提供经操作人员明确接受的保守口径：旧凭据累计调用数全部计入当前订阅月及当前北京时间自然日；当前分钟使用旧分钟计数。已有新计数继续保留。

该口径可能使额度提前耗尽，不会放大授权。缺失累计计数但仍有正数历史计数、无效计数、来源不完整、目标溢出或周期不明确时拒绝执行，不伪造零用量。

本工具首期仅支持来源凭据均有当前有效版本周期的组合。跨历史版本、多租户历史导入、完整计量日志重建和大规模 Redis 停顿评估仍待完成，TRD-BE-011 不因此整体标记完成。Redis 原子校验中的扫描为显式维护操作，应避开高峰；当前针对单实例 Redis，不宣称 Redis Cluster 迁移已验证。

## 续费界面修复

真实浏览器测试发现登录接口缺少企业认证状态，导致合法企业管理员的续费按钮不可见。会话接口补充认证状态、活动成员关系；平台管理角色不采用遗留企业成员关系。续费上下文使用订单所属的合格企业，不以默认企业阻止其他已加入企业的订单操作。

浏览器使用隔离的真实 PostgreSQL 订阅夹具验证展示，夹具经可信交付钩子创建，不将它冒充第三方开通或网关健康验证。真实网关健康和支付交付链路由独立运行集成脚本验证。
