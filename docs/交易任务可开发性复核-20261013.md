# 交易任务可开发性复核

## 范围和原则

复核开发进度控制台中9项进行中任务和7项待开发任务。当前环境具备单节点Kubernetes、PostgreSQL、Redis、MinIO、原生APISIX、模拟API/模型API/SaaS及模拟支付，支持应用层开发与实际链路验证。实际银行支付、真实第三方应用和多节点基础设施故障不具备完整验证条件。

任务完成须同时满足任务自身验收标准；依赖尚未完成或仅有部分验证证据时不得标记为完成。用户待验收任务不自动代替用户验收。测试使用独立数据库区域或有精确所有权记录的临时业务对象，禁止清空共享数据库、队列和网关。保留订单ORD-261012005144E1B3及其依赖产品。

## 不具备完整验证条件的任务

- BE-024、QA-006、FLT-QA-002：缺少真实支付账户、支付账及银行/分账渠道。先保留模拟支付和人工到账验证；接入真实渠道后补测外部资金一致性。
- FLT-QA-003：缺少真实第三方API/SaaS测试地址、授权和幂等契约。先验证本地模拟服务；模拟结果不能宣称已完成真实供应商联调。
- FLT-OPS-001：缺少隔离多节点PG/Redis/存储高可用环境。可验证应用Worker重启和租约恢复，但不能宣称基础设施故障切换通过。
