## 2. 审查发现及修正

| 原问题 | 修正 |
| --- | --- |
| RENEW仍为旧billing_cycle示例 | 完整请求/响应、subscription_months、starts_at、expires_at及完整订单上下文 |
| 续费截止的来源不明确 | 平台先计算并冻结，第三方执行，返回仅作核验 |
| 普通续费CAS与退款缩期混淆 | 明确普通RENEW没有expected_expires_at；退款缩期才使用该字段 |
| OPEN示例过早给出期限 | 新版OPEN准备租户，期限provisional，后续RENEW激活 |
| 同企业多租户描述落后 | 同企业同产品复用单组合，续费不另开租户 |
| 成功数据允许仅放data | 明确关键身份/状态字段必须响应根节点，ret为整数0 |
| USER_ASSIGN缺外部映射证明 | 补external_user_id、platform_user_id及初始主管理员字段差异 |
| 健康检查接口定义不全 | 管理GET /health与应用公开HEAD分开，明确认证、超时及状态码 |
| OAuth角色及Scope不清晰 | 增加完整时序、内省规则、操作Scope映射及凭据族隔离 |
| OIDC仅有基础片段 | 增加端到端时序、PKCE代码、精确参数约束、换码和UserInfo响应及会话规则 |
| 重试描述与实现不符 | 明确实际3次/10秒、分阶段交付与Saga区别，不假设retryable自动调度 |
| 兼容管理接口被当作新交易入口 | 区分平台/第三方责任，新版订单Saga与历史入口分开 |
| 未说明独立持久化需要 | 补租户/用户/部门/订单时段/回执/会话的最小持久化表及唯一键建议 |
| 缺可执行验收路径 | 增加curl示例、14项测试矩阵和常见问题定位 |
