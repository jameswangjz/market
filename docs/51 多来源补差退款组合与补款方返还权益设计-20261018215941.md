# 多来源补差退款组合与补款方返还权益设计

## 1. 已确认业务边界

本次补齐多经济段补差退款、外部补款退款、补差与不可返还成本例外组合。买方退款不得超过其实际实付的剩余可退金额；内部清算调整不扩大买方退款额度。保留已完成的资金、资源回执，不为重新计算而改写原始支付。

外部补款示例：买方实付150元，提供方另补10元，最终清算160元；买方退款30元，按最终清算同比例冲回32元。额外2元形成原补款方返还权益，不增加买方退款，不自动认定已返还。

## 2. 计算与不可变证据

逐经济段锁定最终确认清算基线、支付来源分配、补差来源、独立复核凭证和已退款累计水位。允许同一真实支付覆盖多个合法经济段，但不得重复占用其可退款金额。

采用累计金额舍入后取本次增量，避免多次部分退款累计超额。每笔退款形成唯一冻结计划和唯一记账记录，重试与并发不得重复冲回或重复产生返还权益。

普通清算冲回满足：清算冲回总额＝买方现金退款＋平台内部承担冲回＋外部补款方返还权益。各来源分项保留原订单、经济段、清算单、凭证及计划哈希关联。

## 3. 补款方返还台账

新增独立返还权益项目，记账类型为 funding_return、方向为应付。该项目不是第六个利润分成方，不混入五方成本及利润分成比例，也不重复消耗原清算分成的冲回预算。

保留原补款主体、来源凭证、币种、应返还、已支付、已抵扣、剩余金额。支持符合主体、币种及来源约束的抵扣，或人工付款登记与独立复核。不将人工凭证描述为银行自动对账。

仅生成权益不代表付款完成。负向清算单及其批次应同时反映收益方回收与补款方返还进度；任一剩余义务未完成，不展示为资金已结清。

## 4. 成本例外组合

逐经济段填写有证据的不可返还成本，经对侧一次审批整张提案。成本保留金额不得超过对应段原应冲回成本，并与已有批准记录累计校验。

以普通冲回为基准：保留成本增加实际有符号成本，并对应减少承担方利润，另记独立承担损失。补款方返还权益及平台内部承担冲回不因成本保留而改变。原始基线、普通冲回和例外应用分别保留，禁止递归套用或重复扣减。

## 5. 权限与展示

平台授权财务角色可按现有权限查看完整台账。提供方仅可查看本方授权范围。第三方补款主体仅因持有返还权益，不得获得原订单全部成本或其他参与方明细权限。

页面分别展示买方退款、清算冲回、内部承担冲回、补款方返还权益及支付/抵扣状态；使用可读订单号、清算单号和批次号。报表及下载保持相同口径。

## 6. 开发与验收

1. 计算模块：多来源证据、精确经济段绑定、累计舍入、历史冻结计划兼容。
2. 执行模块：真实退款回执接入、唯一记账、返还应付、来源预算及抵扣约束。
3. 成本例外：逐段证据、对侧审批、累计上限、独立损失记录。
4. 报表及前端：独立返还权益、资金进度、年度桥接、权限隔离。
5. 验证：先聚焦单元测试，再分组执行实际数据库并发/重复回调、退款到清算组合及浏览器展示，不对每个小改动重复全平台回归。

本文件为已确认设计，不代表实现或验证已完成；任务以实际测试证据更新。真实银行支付及自动银行对账不在本轮验收范围。
