# 已售版本保护与线下订单并发验收

## 本批开发

- 产品详情接口增加 `delivery_fields_locked`、每版本 `is_sold` 标记，不输出关联订单ID。
- 以历史已付款订单判断版本已售；已售后冻结价格、成本、版本文件和接入配置，前端跳过重复写入已有接入配置。
- 产品级交付方式和接入地址与现有后端冻结规则一致；仍可新增版本。保护由后端校验兜底，不信任前端标志。
- 版本编辑使用禁用fieldset；移动端新增版本按钮不折行，路径前缀复选框与文字同排。

## 验证结果

- 后端业务回归317项通过；新增并发脚本专项5项通过；前端81项通过；生产构建通过。
- 在开发环境真实PostgreSQL中验证培训、咨询、定制开发：每类重复付款、审核先行、付款先行、双审核竞争，共12场竞争。
- 每场通过 `pg_blocking_pids` 观察两个独立连接被同一订单行锁阻塞，再释放锁验证结果。
- 重复付款均幂等成功；审核先行允许随后付款，付款先行在未审核时返回409；双报价仅一个200、另一个409。
- 检查唯一支付记录、唯一线下交付任务、正确金额快照和状态、审计、通知及计量无重复。
- 三类订单均验证通知失败导致事务完整回滚，重试后只生成一次支付和交付记录。
- 测试使用独立ID，持久化0600恢复清单；已清理并确认关联外键无残留。没有改动用户已有测试产品。
