# API网关详情弹框与分页样式修复

## 需求与修改范围

- 网关主列表分页与其他列表复用同一个组件，每页条数、当前页及跳页控件在桌面宽度下同行展示。
- 路由详情改为弹框，使用统一 ConsoleTabs 展示调用统计、发布记录、告警；各页独立保留分页，告警处置记录仍可查看。
- 弹框提供关闭按钮及 Escape 关闭、键盘焦点约束和焦点返回；点击遮罩不关闭。告警说明弹框保持在详情弹框上层。
- 窄屏允许分页自然换行，但每页和跳至标签与对应输入控件不拆成上下两行。

## 原因与设计

原内联详情使用 settings-tabs，触发全局 `.content:has(.settings-tabs)` 表单样式，分页 label 被改成纵向布局。实际浏览器复现确认两个分页区 label 的 flex-direction 均为 column。

替换为标准 Tab 组件，并在共享 PaginationControls 中明确横向标签、固定输入宽度、30px 高度，抵御系统设置和弹框的表单样式串扰。

关闭及重新打开详情后，前一次详情请求和告警操作响应不能写入新会话。未新增路由配置或发布入口，未修改后端或业务数据。

## 用户验收入口

打开开发环境 `/console?view=gateway`，必要时选择全部产品状态后检索。

1. 主列表分页的每页、页码、跳至为紧凑同行布局。
2. 点击眼睛图标打开详情弹框，切换三个 Tab，确认样式与平台其他 Tab 一致。
3. 确认各 Tab 分页布局正确；关闭弹框后仍在原列表。
4. 窄屏弹框不超出屏幕，长表格可横向浏览，分页标签与输入保持同行。
